# QRV.network Page Map

## Primary navigation

- `/protocol` — QRVP-1 protocol overview and infrastructure model
- `/how-it-works` — scan, resolve, registry lookup, validation, result
- `/registry` — registry services, explorer, records, and transparency
- `/use-cases` — certificates, identity, products, documents, assets, events
- `/developers` — API access, docs, SDK direction, integration support
- `/about` — QR-V mission, origin, founder profile, and infrastructure vision

## Utility routes

- `/verify` — handoff to public verification
- `/issuer` — handoff to issuer portal
- `/docs` — documentation entry
- `/pricing` — issuer and enterprise pricing
- `/status` — root public network status page
- `/store` — store or WordPress handoff if used
- `/network` — service directory and domain map
