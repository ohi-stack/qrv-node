# QRV.Network — Commercialization Baseline

The public platform's immediate purpose is to convert qualified organizations into QR-V Verified Certificate pilots and paying issuers.

## Primary conversion path

```text
problem awareness
→ live verification demo
→ Verified Certificate Pilot
→ demo / qualification
→ payment or approved pilot
→ issuer onboarding
```

## Primary audience

Organizations that issue records another party must trust or verify, especially:

- training/certification providers;
- continuing-education and workforce programs;
- professional associations;
- private academies;
- employers with internal training;
- other credential issuers.

## Public messaging hierarchy

1. Business outcome: independently verify issuer, authenticity, and current status.
2. Live demonstration: show VERIFIED / REVOKED / EXPIRED lifecycle.
3. Product: Verified Certificate Pilot.
4. Technical credibility: QRVP-1, registry, integrity, revocation, API.
5. Enterprise expansion: identity, documents, products, assets, and APIs after product-market evidence.

## Do not lead with

- speculative blockchain claims;
- a mobile scanner roadmap;
- protocol complexity before the customer problem;
- unsupported claims that QR-V is the first verifiable credential or first QR authentication system.

## Primary CTA

Use one dominant commercial action on high-intent pages:

```text
Start Verified Certificate Pilot
```

Secondary action:

```text
See Live Verification Demo
```

The public site must not expose private admin, registry credentials, signing secrets, or unrestricted issuer APIs.
