# QR-V Platform Page Contract

## Primary public pages

- `/` — enterprise homepage and live-network entry
- `/protocol` — QRVP-1 overview
- `/how-it-works` — deterministic issuance and verification flow
- `/verify` — public verification form
- `/registry` — public registry lookup
- `/explorer` — registry inspection entry
- `/use-cases` — certificates, membership, products, documents, assets
- `/developers` — developer onboarding
- `/docs` — documentation index
- `/api-reference` — REST API contract and examples
- `/pricing` — issuer plans and implementation offers
- `/status` — network status
- `/network` — platform/service topology
- `/store` — commercial product catalog entry
- `/about` — QR-V overview and origin
- `/security` — security model
- `/standards` — QVS-1.0 overview
- `/enterprise` — enterprise and white-label offer
- `/certificate-verification` — flagship certificate product
- `/contact` — sales/support contact entry
- `/terms` — terms
- `/privacy` — privacy

## Issuer application pages

- `/issuer` — authentication
- `/issuer/dashboard` — issuer metrics and quick actions
- `/issuer/records` — issuer-owned records
- `/issuer/records/new` — issue a new QR-V record
- `/issuer/logout` — terminate session

## Operational endpoints

- `/health`
- `/healthz`
- `/readyz`
- `/version`

## Navigation standard

Primary: Protocol, How It Works, Verify, Registry, Use Cases, Developers, Pricing, About.

Utility: Issuer, Status.

Footer groups: QR-V, Technology, Resources, Commercial.

## Conversion priority

Every major public page should lead toward one of three actions: Verify a record, Become an Issuer, or Contact Enterprise Sales.
