# QR-V Brand Assets

Production user interfaces use the QR-V Global Verification Network logo, dark navy foundation, electric blue accents, white typography, and verification-state colors that remain readable without color alone.

Repository assets:

- `public/qrv-global-verification-logo.png`: primary horizontal brand mark;
- `public/qrv-favicon.png`: application icon;
- `public/qrv-network-production-hero.jpeg`: approved network vision artwork for campaigns and editorial surfaces;
- `docs/assets/source-records/qrv-network-overview.jpeg`: optimized network overview source record;
- `docs/assets/source-records/qrv-innovation-blueprint.jpeg`: seven-layer innovation source record.

Do not use source artwork as evidence that a service is live, encrypted, verified, or operational. Live status and verification claims must come from runtime checks. Text embedded in artwork must be reviewed before public publication.
